# Kanto 151 – offline scanner test

This repository deploys the `offline-scanner` branch from the main Kanto 151 repository as a separate GitHub Pages test site.

The production repository and its Pages site are not changed by this deployment.

## Deployment
Run the **Deploy offline scanner test** workflow from the Actions tab, or push a change to `main`.

After the first deployment, the test site is available at:
https://y5dk674ks8-svg.github.io/kanto151-vintage-test.-offline/

The scanner is intended to process one front-side photo locally in the browser using the bundled OCR runtime. No paid API is configured.
